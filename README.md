# Информационная система детского творческого центра (выпускная квалификационная работа)

Десктопное приложение для администратора творческого центра: заявки и ученики, договоры и оплаты, группы и расписание, задолженность, KPI и отчёты. Чат-бот мессенджера MAX работает с той же базой: диалоги, команды, запись на пробное занятие и рассылки открываются из программы.

Стек: C#, WPF, .NET 8, PostgreSQL, Npgsql, MAX Bot API, ClosedXML, BCrypt.

## Что умеет система

- карточки гостей и перевод гостя в ученика, представители и семья;
- группы, расписание, посещаемость, пробные занятия;
- договоры, оплаты, долги, продажи, расходы, зарплата преподавателей;
- роли: администратор, руководитель, старший менеджер, менеджер, преподаватель;
- пароли в BCrypt, блокировка входа после серии ошибок, токен бота через DPAPI;
- экспертная аналитика оттока по правилам (посещаемость, долг, срок договора);
- фоновая служба `MaxBotWorker`, которая опрашивает MAX, пока программа закрыта.

Демо-данные клиентов в репозиторий не входят. Схема создаёт пустую базу.
